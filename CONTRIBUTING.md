# Contributing to Lumaquince

Report fork-specific problems and propose changes at
[yoyodapro/Lumaquince](https://github.com/yoyodapro/Lumaquince).

Read the [known issues](KNOWN_ISSUES.md), [gameplay profile](GAMEPLAY-PROFILE.md)
and [validation record](VALIDATION.md) first. Include the release version and EXE
checksum, game/update build, GPU/driver, relevant settings, Adaptive Timing state
and reproducible steps. Review the [privacy guidance](PRIVACY.md) before posting
minimal diagnostic excerpts. Remove personal paths, account data and private URLs;
do not attach game/system files, saves, caches, dumps or raw GPU captures.

See the [build guide](docs/Build.md) for your platform and the
[coding guidelines](docs/Coding.md) for technical guidance. Keep changes focused,
describe what you tested, and distinguish build checks from gameplay testing.

Original copyright notices and third-party licenses remain in effect. See
[LICENSE.txt](LICENSE.txt) for the project's license.

The exact compiled preview source is tagged `source-v0.1.0-preview.1`. The
`v0.1.0-preview.1` publication tag also contains the public setup and validation
documents; those documentation changes do not rebuild the release binaries.
